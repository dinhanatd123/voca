Sổ Tay Cụm & Câu Công Sở Cấp Tốc (Copy & Dùng Ngay)

Tổng hợp các cụm từ (Chunks) và mẫu câu hoàn chỉnh cho Email, Slack/Teams, Họp hành và Đàm phán. Bấm 1 chạm để copy hoặc nghe phát âm.

Tài liệu kỹ thuật dành cho Developer / Product Owner

Thiết Kế Cơ Sở Dữ Liệu (Database Schema) & Luồng Hệ Thống

Cấu trúc bảng quan hệ chuẩn hóa giúp quản lý 1 từ gốc liên kết với nhiều Cụm từ (Chunks/Collocations) và biến thiên theo 4 ngữ cảnh (TOEIC, IELTS, Công sở, Đời thường), kèm thuật toán Spaced Repetition (SM-2).

Bảng 1 • Core Entity

words (Từ gốc)

Lưu từ vựng nguyên bản, phiên âm IPA, file audio UK/US, từ loại (POS), mức độ CEFR (A2–C2) và nghĩa cốt lõi.

id, lemma, pos, ipa_us, ipa_uk, core_meaning_vi, cefr_level
Bảng 2 • 1-N với words

word_chunks (Cụm từ)

Lưu các Collocations, Phrasal Verbs, Idioms gắn với từ gốc kèm cấu trúc ngữ pháp (예: v + adj + n) và tần suất xuất hiện.

id, word_id, chunk_text, pattern, meaning_vi, register_tag
Bảng 3 • 1-N với chunks

context_sentences (Câu)

Lưu câu hoàn chỉnh phân loại theo 4 luồng (`toeic`, `ielts`, `office`, `daily`), bản dịch, highlight vị trí cụm và ghi chú band/tone.

id, chunk_id, domain_type, sentence_en, sentence_vi, usage_note
Bảng 4 • Học tập & AI

user_srs_progress

Theo dõi tiến độ nhớ của từng user ở cấp độ Cụm/Câu (thuật toán SM-2: `interval_days`, `easiness_factor`, `next_review_at`).

user_id, chunk_id, step_completed, interval_days, next_review_at
PostgreSQL Schema (Chuẩn hóa 3 Tầng + SRS) 
CREATE TYPE context_domain AS ENUM ('toeic', 'ielts', 'office', 'daily');

-- 1. Bảng Từ gốc (Tầng 1)
CREATE TABLE words (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  lemma VARCHAR(100) NOT NULL UNIQUE,
  pos VARCHAR(30) NOT NULL, -- verb, noun, adj...
  ipa_us VARCHAR(100),
  core_meaning_vi TEXT NOT NULL,
  memory_tip TEXT,
  cefr_level VARCHAR(5) DEFAULT 'B2'
);

-- 2. Bảng Cụm từ / Collocations (Tầng 2)
CREATE TABLE word_chunks (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  word_id UUID NOT NULL REFERENCES words(id) ON DELETE CASCADE,
  chunk_text VARCHAR(255) NOT NULL,
  grammar_pattern VARCHAR(120),
  meaning_vi TEXT NOT NULL,
  domain context_domain NOT NULL
);

-- 3. Bảng Câu hoàn chỉnh theo ngữ cảnh (Tầng 3)
CREATE TABLE context_sentences (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  chunk_id UUID NOT NULL REFERENCES word_chunks(id) ON DELETE CASCADE,
  domain context_domain NOT NULL,
  situation_label VARCHAR(120), -- VD: Email xin lùi deadline, IELTS Task 2
  sentence_en TEXT NOT NULL,
  sentence_vi TEXT NOT NULL,
  tone_badge VARCHAR(60) -- VD: Formal Business / Band 7.5+
);

-- 4. Bảng Tiến độ Lặp lại ngắt quãng (SRS SM-2)
CREATE TABLE user_srs_progress (
  user_id UUID NOT NULL,
  word_id UUID NOT NULL REFERENCES words(id) ON DELETE CASCADE,
  status VARCHAR(20) DEFAULT 'due', -- due, learning, mastered
  interval_days INT DEFAULT 1,
  easiness_factor NUMERIC(3,2) DEFAULT 2.50,
  next_review_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  PRIMARY KEY (user_id, word_id)
);
