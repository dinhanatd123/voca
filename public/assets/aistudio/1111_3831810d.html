🗄️ System Architecture & PostgreSQL Schema

Thiết kế Cơ sở dữ liệu & JSON API

Mô hình dữ liệu quan hệ 4 bảng chuẩn hóa phục vụ học từ vựng 3 tầng, đa ngữ cảnh và thuật toán lặp lại ngắt quãng SM-2.

1. TABLE words
Lưu trữ Tầng 1 (Core Word)
  • • id (UUID PK)
  • • word_text (VARCHAR UNIQUE)
  • • pos, cefr_level (B2/C1)
  • • ipa_us, ipa_uk
  • • core_meaning_vi, exam_trap
2. TABLE word_chunks
Lưu trữ Tầng 2 (Collocations)
  • • id (UUID PK)
  • • word_id (FK → words.id)
  • • context_type (toeic/ielts/...)
  • • chunk_en, chunk_vi
  • • register_note
3. TABLE context_sentences
Lưu trữ Tầng 3 (Full Sentences)
  • • id (UUID PK)
  • • chunk_id (FK → word_chunks.id)
  • • sentence_en, sentence_vi
  • • grammar_highlight
  • • audio_url
4. TABLE user_srs_progress
Tiến độ SM-2 & Lịch sử AI
  • • user_id, word_id (Composite PK)
  • • srs_status (review/learning/...)
  • • easiness_factor (FLOAT 2.5)
  • • interval_days, next_review_at
  • • last_ai_sentence, ai_score
